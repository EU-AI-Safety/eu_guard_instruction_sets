## Files

- `sft_*.jsonl` - `messages` [system, user, assistant] + metadata
- `dpo_fixed_*.jsonl` - TRL conversational pairs, original rule-fixed rejected (SAFE -> VIOLATION/G1, otherwise -> SAFE)
- `dpo_hardneg_*.jsonl` - same prompts/chosen, hard rejected; `neg_type` records which kind
- `eval_{val,test}.jsonl` - `prompt` messages + `gold` JSON string, for generation-based scoring

The jsonl files are gitignored (~170 MB); rebuild with `python scripts/build_classifier_data.py` (deterministic for a given seed).

Metadata fields: example_id, concept_id (= meta_id), split, language, label, category_id, source_group, scenario_type, augmentation, source_run, generator, target (SAFE -> should_answer, else should_refuse; for compatibility with eu-guard-dpo-main's loader), pair_type (= gold label).
